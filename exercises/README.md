# Python Practice Exercises

Run these examples from the `day-02` folder with `..\venv\Scripts\python.exe` while your working directory is `exercises`, or with the root-relative commands in the main README.

- `fundamentals.py`: variables, built-in types, operators, conditions, loops, functions, lambda expressions, comprehensions, and exception handling.
- `oop_and_files.py`: classes and objects, inheritance, encapsulation with a property, JSON file read/write, and a context manager.
- The complete Add/Update/Delete/Search/Filter/Sort/Statistics management assignment is implemented in `../system/`.
- CSV and JSON record analysis practice is implemented in `../analysis/`.

Try extending the examples before reviewing the practical application. Keep input validation and useful error messages in your changes.
